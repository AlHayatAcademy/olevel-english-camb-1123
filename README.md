# English1123 Study Hub

A static HTML/CSS/JavaScript learning website structured around Cambridge O Level English Language 1123 (2027–2028). This is an independent educational resource and is not affiliated with or endorsed by Cambridge International Education.

## Run locally
Open `index.html` directly, or serve the folder with any static server.

## GitHub
Create a repository and upload all files in this folder (keep the directory structure).

## Cloudflare Pages
1. Push the project to GitHub.
2. In Cloudflare Dashboard, open Workers & Pages > Create > Pages > Connect to Git.
3. Select the repository.
4. Framework preset: None.
5. Build command: leave blank.
6. Build output directory: `/` (repository root).
7. Deploy.

## Content note
Do not copy Cambridge past papers, mark schemes, or copyrighted syllabus prose into the site without permission. Add your own original teaching content and practice tasks.
